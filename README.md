# けんきあそび（3D 建機あそび・算数学習アプリ）

6 歳前後の子どもが Android タブレットで遊べる 3D 建設機械シミュレーター。
現在は **Phase 4：ミッション・算数（岩を運んで足し算・クリア）** まで実装済み。

## 起動方法

```bash
npm install
npm run dev
```

- PC：表示された `http://localhost:5173/` を Chrome で開く
- タブレット：PC と同じ Wi-Fi につなぎ、`npm run dev` に表示される `Network:` の URL（例 `http://192.168.x.x:5173/`）をタブレットの Chrome で開く
  - 左上の「全画面」ボタンで全画面＋横向き固定（Android Chrome）
- `?fps` を URL に付けると FPS を表示（例 `http://localhost:5173/?fps`）
- `?physics` を付けると当たり判定の形を表示（開発用。`?fps&physics` のように併用可）

その他のコマンド：

| コマンド | 内容 |
| --- | --- |
| `npm run build` | 型チェック＋本番ビルド（`dist/`） |
| `npm run preview` | ビルド結果をローカルで確認 |
| `npm run typecheck` | 型チェックのみ |

## 公開・オフライン

- GitHub（`keidaizm/construction_game`）の main に上げると、Vercel が自動でビルドして公開する：https://construction-game-rho.vercel.app
- **PWA**：一度ネットにつないで開くと、ゲームのファイルがブラウザに保存され、**オフラインでも遊べる**（`public/sw.js`）。
  ホーム画面に追加すると全画面・横向きのアプリとして開ける（`public/manifest.webmanifest`）
- 新しい版を公開すると、ネットにつながったときに自動で入れかわる。ゲーム本体は約 3.5MB（転送は約 1.2MB）、セーブは数十 KB
- セーブは「そのブラウザの、そのアドレス」に保存される（開発用の localhost と公開 URL は別の記録）

## あそびかた

### 探検と色の石

- フィールドは約 520m 四方。木・大きな岩・タワークレーン（基地の目印）がある。木や岩にぶつかると車両は止まる
- スタートはフィールドの中心（おきばもすぐ前）。石は 4 色（ふつう・くろ・あか・しろ）で、中心から 105〜135m の輪の上に
  色ごと 2 か所ずつ、方角ごとに色が変わるように置いてあり、その色の旗が立っている
- 上のミッションの札は、左に「あと ◯こ」（多すぎると「おおい ◯こ」）。色が 2 つ以上のときは、色ごとに「岩の絵・2/3・小さな丸」を横に並べる
- ミッションは「くろい いし 3こ ＋ あかい いし 2こ」のように色ごと。色ごとの数がそのまま式 `3 + 2 = 5` になる
- **コンパスの矢印**：乗っている車両の足元に、まだ足りない色ごとに 1 本ずつ矢印が出て、その色のいちばん近い石を指す（足りた色は消える）
- **地図**：左上の地図ボタン（または M キー）で画面いっぱいの地図。行ったことのある場所だけ見え、まだの場所は **灰色の雲と「？」** でかくれている
  （行くと晴れる）。走れる範囲の外は山の色。左上に **たんけん ◯%**（バー）。
  **100% にすると「ちず コンプリート！」のお祝い（花吹雪）と、星 +5**（1 回だけ。星でグレードアップしたらそれも出る）。
  いま集める色の石の場所は黄色い輪で光る。どこをタップしても閉じる。行った記録はブラウザに保存される

### 地帯・池と川・丘

- 基地のまわりはいつもの土。離れると方角ごとに景色が変わる：**北＝雪原**（雪をかぶった木）／**東＝草原と森**（丸い木）／**南＝砂漠**（サボテン）／**西＝岩山**（大きな岩が多い）。
  地図も地帯の色になる
- **川と湖**（東の森）：車両は水に入れない。川には **木の橋** が 2 本あって渡れる。**オアシス**（南の砂漠、ヤシの木）。**凍った池**（北の雪原）は上を走れる。
  水に落ちた石は置き場に戻る
- **丘**（雪原・砂漠・岩山・森に 15 こくらい。岩山は高め）：車両は丘にそって傾いて走る。石も丘を転がる。
  遊びに使う場所（基地・おきば・石の置き場・土の山・水・名所・宝箱）は平らなまま

### 宝の山・名所・宝箱

- **宝の山**：各地帯の外側（中心から約 150m）に 1 こずつ、地帯の色の土の山（宝石の粒が光るブロック）。★3 以上の鉱石が 3 倍出やすく、
  **その地帯だけの鉱石**（こおりの けっしょう・ひすい・さばくの バラ・こくようせき、★4）も出る。地図では黄色い点線の輪
- **名所**：各地帯に 1 つ（おおきな ゆきだるま・かざぐるまの とう・ピラミッド・ちいさな かざん）。近くへ行くと「◯◯を はっけん！」
- **宝箱**：各地帯に 2 こ（全部で 8 こ）。車両でさわるとふたが開いて鉱石が 1 こ出てくる（★2 以上。山よりレアが出やすい）。全部開けると、少しして全部また閉じる
- 図鑑の **「はっけん」** タブで、見つけた名所と開けた宝箱の数が見られる。名所・宝箱は地図にも出る（行ったことのある場所なら）

### ミッションの種類

ミッションは毎回かわる（はこぼう 約半分・つくろう・とりのぞこう）。最初のミッションは「はこぼう」。

| 種類 | 内容 | 式 |
| --- | --- | --- |
| はこぼう | 「くろい いし 3こ ＋ あかい いし 2こ」のように、色と数が決まっている（ほかの色はおきばに入っていても数えない） | `3 + 2 = 5` |
| ◯を つくろう | 好きな色の石を 2 しゅるい以上あわせて、合計をぴったりに（Lv1 は 5、Lv2 は 10、Lv3 は 10〜20） | `4 + 6 = 10` |
| とりのぞこう | はじめからおきばに石があり、ショベルで取り除いてぴったりの数にする（とりすぎたら戻す） | `8 − 3 = 5` |

- ときどき、フィールドのどこかに **金色の石** が出る（金色の光の柱が目印）。バケットですくうと星が 1 こもらえる。矢印は出ないので探検して見つける（地図には、行ったことのある場所なら★で出る）

### 掘る・鉱石・図鑑

- 石の置き場の間に **土の山**（6 か所）がある。バケットを山に入れると土ブロックが崩れ（土ぼこりと音）、ときどき中から出てくる：
  ふつうの石 約 25%・色の石 約 10%・鉱石 約 10%（のこりは土だけ）。出てきた石はミッションにも使える
- 鉱石は 9 種類＋夕焼けだけ 3 種類＋夜だけ 3 種類（マインクラフトを参考）：せきたん・てっこうせき・どうこうせき・きん・ラピスラズリ・ルビー・エメラルド・きょうりゅうの ほね・ダイヤモンド。
  レアなものほど出にくい（ダイヤモンドは約 0.25%）。見つけると宝石がきらきら浮かび、「◯◯ を みつけた！」（はじめてなら「あたらしい！」）
- 左の **図鑑ボタン**（レベルの下）で図鑑を開く。見つけた鉱石はカード（名前・レア度の★・見つけた数）、まだのものは影と「？？？」。図鑑はブラウザに保存される
- 土の山は「はじめから」や次のミッションで元に戻る

### 昼・夕焼け・夜

- 右上（のりかえボタンの左）の **時間帯のボタン** を押すたびに **昼 → 夕焼け → 夜 → 昼…** と変わる（ボタンには次の時間帯の絵：夕日・月・太陽）。
  空や光はなめらかに変わる。N キーでも切り替え
- 夜は月明かりでうっすら見える（星と月も出る）。矢印・おきば・▼ などの目印は夜でも明るいまま
- 夕焼けと夜は **ライトのボタン**（H キー）が出る。押すと乗っている車両のライトが点き、前を照らす（ショベルは運転席の向き）。昼に戻ると消える
- **夕焼けだけの鉱石** 3 種類：こはく（★3）・サンストーン（★4）・にじいろ オパール（★5）。夕焼けに土の山を掘ったときだけ出る（合わせて約 2.7%）。
  図鑑では夕日の印
- **夜だけの光る鉱石** 3 種類：グロウストーン（★3）・アメジスト（★4）・ほたるいし（★5）。夜に土の山を掘ったときだけ出る（合わせて約 2.6%）。
  図鑑では月の印が付いている（図鑑は全部で 15 種類）

### 音

- エンジン音（乗っている車両・動かし方で変わる）・油圧の音・石の音・バックの警告音・数えたときの「ポコッ」・クリアのファンファーレ・グレードアップ・鉱石を見つけた音
- 効果音ファイルは使わず、ブラウザの音声合成（Web Audio）で作っている。最初に画面をタッチしたときから鳴る
- 左上のスピーカーのボタンで音のオン／オフ（保存される）
- ほかのアプリやタブ・ウィンドウに切りかえると音が止まり、戻ると続きから鳴る

### ミッション（ぴったり運ぼう）

画面の上に「いわを 5こ ぴったり はこぼう！」・岩の絵（運ぶたびに 1 個ずつ埋まる）・`0 / 5`・「あと 5こ」が出る。
ショベルカーで岩をすくってダンプに積み、ダンプで **おきば**（緑の円と旗・浮かぶ緑の ▼）まで運んで降ろす。

- **ぴったり**運べたらクリア。**いま緑の円の中にある岩**を毎回数え直す（転がり出たら減る、円の外の岩は数えない）。
  中の数がしばらく変わらず、近くで転がっている岩もなくなってから判定する
- 1 回の荷下ろしが 1 つの数になり、2 回目からは `2 + 3 = 5` のように足し算の式が出る
- ダンプの荷台の上に **いま何こ載っているか** の札が出る。残りより多いと赤く「おおい」になり、荷台の岩の上に黄色い ▼ が出る。
  ショベルで荷台から岩をすくい出して減らせる
- 多く降ろしてしまったら「2こ おおい！ ショベルで とりのぞこう」と出る。ショベルでおきばから岩を持ち出して外に置き、
  ぴったりになったらクリア（バケットに岩を持っている間は確定しない）。おきばの岩の ▼ は多すぎるときだけ出る
- 岩を積んだダンプに乗っていると、トラックの上に **緑の矢印** が出て、おきばの方向を指す。三角コーンの道をまっすぐ進むと着く
- 黄色い ▼ =「とれる」、緑の ▼ =「ここへはこぶ」

### 星とグレードアップ

クリアすると星がもらえる（最大 3 こ）：★ クリア ／ ★ おおすぎずに できた ／ ★ 2かい いじょう はこんだ（足し算の式ができた）。
集めた星は左上に出て、ブラウザに保存される（次に開いても続きから）。星がたまるとグレードアップする：

| レベル | 必要な星 | バケット | 一度にすくえる数 | ミッションの数 |
| --- | --- | --- | --- | --- |
| Lv1 | 0 | ふつう | 3 こ | 3〜5（1 色） |
| Lv2 | 9 | 1.3 倍（爪が青） | 5 こ | 5〜10（1〜2 色） |
| Lv3 | 24 | 1.6 倍（爪が金） | 8 こ | 10〜20（2〜3 色・繰り上がり） |

- 目標の数は範囲の中から毎回変わる（前回と同じ数は出ない）ので、何度でも遊べる
- 岩の絵は 5 こ・10 こずつのまとまりで区切って表示する（数えやすく、10 のまとまりが見える）
- 左上の **レベルの札（Lv◯ ★◯）を押す** と、レベルの一覧が出る：いまのレベル・次のレベルまでの星（バー・あと ◯こ）と、Lv1〜6 でできること（まだのレベルは鍵）
- 星をどこでもらっても（ミッション・クレーン・金色の石・地図コンプリート）、レベルが上がったら **グレードアップのお祝い** が出る（Lv3 はクレーン、Lv4 はブレーカーが使えることも出る）
- **セーブ**：ブラウザに自動で保存される。星・レベル・地図・図鑑・はっけん・家に加えて、**途中のミッション・車両の場所と姿勢・動かした石や木材・割った岩・倒した木・時間帯・乗っている車両** も
  2 秒ごと（と、ほかのアプリに切りかえたとき）に保存し、開き直すと続きから遊べる。ブラウザの閲覧データを消すと消える
- 保護者向け：URL に `?reset-progress` を付けて開くと、集めた星・地図の記録・図鑑・はっけんの記録を消して Lv1 からやり直せる

### 岩をすくう（ショベルカー）

1. スタート地点の前に岩置き場（少し暗い土の円）がある。前進して近づく
2. バケットが近づくと、すくえる岩の上に **黄色い ▼** が浮かぶ
3. ブームを下げ、アームを押し出して、バケットを岩の向こう側へ下ろす
4. アームを引き込みながらバケットを巻き込むと、岩がバケットに入る（ぽよんと少し膨らむ）。一度に最大 3 個
5. ブームを上げ、上部旋回で好きな場所へ向ける
6. バケットを開くと、岩がゴロゴロ落ちる（ブームを上げていても、アームを引いていても、開き始めればすぐ落ちる）

- 落とした直後の岩は 1 秒間すくえない（落とした瞬間にまた吸い込まれないように）
- 場外や地面の下に落ちた岩は岩置き場に戻る。↻ ボタン（R キー）でショベルカーもダンプも岩も最初の状態に戻る

### ダンプに積んで運ぶ

1. ダンプカーはショベルカーの左側に止まっている。岩をすくったら **左に旋回** してバケットを荷台の上へ
2. バケットを開くと岩が荷台に落ちる（荷台の近くなら、少しずれていても荷台の中へ落ちる）。荷台の床より下へはバケットが入らない
3. 右上の **のりかえボタン**（次に乗る車の絵）を押すとダンプカーに乗り換わる。カメラもダンプへ移る
4. ジョイスティックで運転する。上 = 進む、下 = バック、左右 = ハンドル（車と同じように曲がる）。荷台の岩は走っても落ちない
5. 好きな場所で、右の赤いレバーを上へ。荷台が上がり、後ろのあおりが開いて岩がゴロゴロ降りる
6. おきばで降ろした岩は、止まったら数えられる（円の少し外まで数える）。レバーを下へ戻して荷台を下げ、もう一度のりかえボタンでショベルカーへ

- 荷台を上げている間は、ゆっくりしか走れない
- ショベルカーとダンプカーはぶつかると止まる（すり抜けない）

### ブルドーザーで押す

- ショベルカーの右どなりに止まっている。のりかえボタンは **ショベルカー → ダンプカー → ブルドーザー → ショベルカー…** の順に回る
- 前の **排土板（ブレード）** で石を押して運ぶ。板のすぐ前の石は、ブルドーザーといっしょに進む（勢いよく転がっていかない）
- 「とりのぞこう」ミッションで、おきばの石を円の外へ押し出すのに使える
- **土の山（土ブロック）は壊せない**。ぶつかると壁のように止まる（ブロックを崩して石を出すのはショベルカーだけ）

### 油圧ブレーカー（Lv4 から・星 36 こ）

- ショベルの操作パネル（ジョイスティックの右）に **アタッチメントの切り替え**（バケット ⇄ 油圧ブレーカー）が出る。B キーでも切り替え
- ブレーカーの **のみ** を、フィールドの **大きな岩** に当てている間、自動で「ガガガ」と叩く（岩がゆれて、ヒビで色が暗くなる）
- 何秒か叩くと岩が割れて、**小さな石が 3〜5 こ** 出てくる（地帯の色：砂漠は赤、雪原は白、岩山は黒、ほかはふつう）。ミッションにも使える
- ときどき **岩だけの鉱石**：ジオード（★3）・いんせき（★4）・ほしの かけら（★5）。図鑑では 🪨 の印
- 割った岩は次のミッション（「はじめから」）で元に戻る。ブレーカーの間はすくえない・土の山は崩せない（バケットに戻す）
- 大きな岩の上では、バケット・のみの先が止まる（岩をつきぬけない）

### 木をたおす・重ダンプ（Lv5・星 44 こ）

- **ショベルが 1.3 倍** に大きくなる（本体・ブーム・アーム。バケットの大きさとすくえる数はそのまま）。バケットは 4m 以上まで上がり、重ダンプに積みやすい
- **ダンプが大きな重ダンプ** になる（大きなタイヤ・左に寄った運転席・運転席の上までのびる荷台のひさし）。荷台は長さ 5.4m・幅 2.9m（ふつうは 4.3m・2.3m）。
  荷台のふちの高さは約 2.7m で、ショベルのバケット（荷台の上で 3.2m 以上まで上がる）で積める

- **ブルドーザー** で、外がわの地帯（雪原・森・砂漠・岩山）の **木** を押し続けると、木がゆれて倒れ、**木材（丸太）が 3 本** 出てくる
  （基地のまわりの木・サボテン・ヤシは倒れない）
- 倒した木は 20 秒たつと、同じ地帯の **木の少ない場所** にまた生えてくる
- Lv5 のあいだ、木材は出てから 30 秒で消える（Lv6 からは消えずに残る）

### グラップルと家づくり（Lv6・星 52 こ）

- ショベルのアタッチメントに **グラップル**（大きなはさみ）が加わる（バケット → ブレーカー → グラップル の順に切り替え、B キーでも）
- グラップルはいつも真下にぶら下がる。**緑のレバー（バケット）** で、上 = つめを開く／下 = 閉じる。閉じると、まん中の近くの木材をつかむ。開くとはなす
- 木材は **ダンプの荷台** に積める（岩と同じように、荷台を上げると後ろから降りる）。木材を積んだダンプには、緑の矢印が家の区画を指す
- 基地の左がわ（地図で見て基地のすぐ左）が **家を建てる場所**（2 列 × 3 つの区画、地図の上下に並ぶ）。黄色い輪（看板「いえ あと ◯ほん」）に木材を置くと、
  1 本ずつ家に使われ、丸太の壁 → 屋根 → 戸と窓 → えんとつ と建っていく。**12 本で 1 けん、星 +3**。となりの区画へ進み、全部で 6 けん（村）。村は保存される
- ブルドーザーで木材を押して運んでも使える

### ビルをこわして てっこつを集める（Lv7・星 60 こ）

- 基地の南（地図の下のほう）に **ふるい ビル**（3 階建て）が出る。**ブレーカー** の先をビルに当てていると、上の階から 1 つずつこわれる（1 階 約 3 秒）
- こわれた階からは **がれき**（コンクリートのかたまりがついた鉄骨）が 2 こずつ、ショベルの前に出てくる。全部こわして 30 秒たつと、ビルは元に戻る
- ショベルのアタッチメントに **スケルトンバケット**（底がすき間の格子のバケット）が加わる。がれきをすくって（3 こまで）、
  **緑のレバー（バケット）を上・下・上・下…と行ったり来たり** させると、すき間から小石がこぼれ、3 往復くらいで **鉄骨だけ** になる
- スケルトンバケットは、大きく開くレバーを入れたときか、口を下に向けたときだけこぼれる（ゆらしている間はこぼれない）
- 鉄骨をダンプの荷台に入れて、基地のそばの **緑の場所（リサイクル場）** で荷台を上げる。止まった鉄骨が 1 本ずつ **てっこつ** になる
  （鉄骨だけを積んだダンプには、緑の矢印がリサイクル場を指す。コンクリートがついたままだと数えない）
- お題「てっこつを ◯ほん あつめよう！」（3〜6 本）。運んだ回ごとの数が足し算の式（2 + 1 = 3）になり、集めきると **星 +2**。集めた てっこつは保存される
- ビル・リサイクル場の近くでは、画面上のお題が てっこつ集めに変わり、いまやること（こわす → ふるう → はこぶ）も出る

### ビルとタワーを建てる（Lv8・星 68 こ／Lv9・星 76 こ）

- 基地の東（地図で基地の右）が **工事現場**。黄色い輪（資材置き場）に **石** を置くと 1 こずつ使われ（使った石は元の置き場に戻る）、
  そろうと **持っている てっこつ** を使って建つ。看板に「石 2/4・てっこつ 1/1」（てっこつが足りないと赤）
- **ビル（Lv8）**：石 4 こ ＋ てっこつ 1 本で 1 階。4 階で完成して **星 +3**、となりの区画へ（全部で 3 つ）
- **タワー（Lv9）**：東京タワーのような赤と白の鉄骨の塔。石 3 こ ＋ てっこつ 2 本で 1 段、足 → 胴 → 大展望台 → 胴 → 特別展望台 → アンテナ の 6 段で完成して **星 +5**
- つぎにできる所はうっすら見える。夜はビルの窓とタワーが光る（ライトアップ）。建てたものは保存される
- 石を積んだダンプで工事現場に近づくと、緑の矢印が資材置き場を指す

### 基地（じむしょ）

- 基地の現場事務所に車両で近づくと、下のまん中に「じむしょに はいる？」が出る。中のメニューから **こうぼう・しゃこ・てんじだな** をえらぶ（◀ でメニューに戻る）
- **じむしょ**：ほし・こうせき・たんけん・いえ・つみきタワー・かざり（つくった数 / 全部）の記録
- **こうぼう**：持っている鉱石で **ペンキ**（みどり・むらさき・ぎんいろ・きんいろ・にじいろピンク・ダイヤモンド・ほたるのひかり）と
  **かざり**（きんのトロフィー・ダイヤのかんむり・きょうりゅうのもけい・ひかるほし・てつのロボット）をつくる。鉱石は「持っている数」が減る（図鑑の記録は減らない）
- **しゃこ**：ショベル・ダンプ・ブルドーザーの色をかえる（きいろ・あか・あおは、はじめから）
- **てんじだな**：つくったかざりと、見つけた鉱石（宝石の絵・持っている数）が並ぶ

### タワークレーン（Lv3 から）

- 基地のタワークレーンの近く（18m）まで車両で行くと、下のまん中に **「クレーンに のる？」** が出る。Lv2 までは鍵の絵と「Lv3 で のれるよ」
- 乗ると **あそびを えらぶ**：
  - **コンテナ はこび**：看板と上の札の式（例 `2 + 3 = ？`）の答えの数字のコンテナを、黄色い台にのせる。せいかいで星 +1、次の問題へ
    式はレベルで増え、出せる種類から毎回ランダムに出る：はじめは 10 までのたし算、**Lv4 から 2けたの たし算**、**Lv6 から ひき算**、**Lv8 から 1けたの かけ算**
  - **つみき タワー**：大きさ・形のちがうブロック（立方体・板・長い棒・柱・三角の屋根）を土台に高く積む。ものさしに いまの高さ（緑）と さいこう記録（オレンジ）。
    さいこう記録は保存され、1m こえるごとに星 +1
- 画面は **横から**（腕に直角）見る。トロリーの「外へ」が画面の右。フックの真下に丸い印と点線（つかめると緑、つかんでいるとオレンジ）
- 下ろしきる手前ではなすと、下のブロック・土台・台のまん中にそろう（向きも 90° ごとにそろう）。高い所ではなすと、そのまま落ちる
- 右上の **おりる** で、乗ってきた車両に戻る。上の「あそびを かえる」でえらぶ画面に戻る

## 操作方法

### タッチ（タブレット）

**ショベルカー**

| 場所 | 操作 | 動き |
| --- | --- | --- |
| 左下 ジョイスティック | 上 / 下 | 前進 / 後退 |
| 〃 | 左 / 右 | その場で左右に旋回 |
| 右上 横レバー（紫） | 左 / 右 | 上部旋回体を左 / 右に回す |
| 右下 縦レバー①（オレンジ） | 上 / 下 | ブームを上げる / 下げる |
| 右下 縦レバー②（青） | 上 / 下 | アームを押し出す / 引き込む |
| 右下 縦レバー③（緑） | 上 / 下 | バケットを開く / 巻き込む（掘る） |
| 左上 ↻ ボタン | タップ | ショベルカー・ダンプ・岩をはじめの状態に戻す |
| 左上 地図ボタン | タップ | 地図を開く（もう一度タップで閉じる） |
| 右上 のりかえボタン | タップ | ダンプカーに乗り換える |

**クレーン**

| 場所 | 操作 | 動き |
| --- | --- | --- |
| 左下 横レバー（紫） | 左 / 右 | 腕を左 / 右に回す |
| 右上 横レバー（青） | 左 / 右 | トロリー（フックを吊る台車）を 塔の方へ / 腕の先へ |
| 右下 縦レバー（オレンジ） | 上 / 下 | フックを上げる / 下げる |
| 右下 つかむ／はなす | タップ | フックの下の荷物をつかむ・はなす（つかめるときは緑に光る） |
| 右上 おりる | タップ | 乗ってきた車両に戻る |

**ダンプカー**

| 場所 | 操作 | 動き |
| --- | --- | --- |
| 左下 ジョイスティック | 上 / 下 | 進む / バック |
| 〃 | 左 / 右 | ハンドルを左 / 右に切る |
| 右下 縦レバー（赤） | 上 / 下 | 荷台を上げる / 下げる |
| 右上 のりかえボタン | タップ | ブルドーザーに乗り換える |

**ブルドーザー**

| 場所 | 操作 | 動き |
| --- | --- | --- |
| 左下 ジョイスティック | 上 / 下 | 前進 / 後退 |
| 〃 | 左 / 右 | その場で左右に旋回（ショベルと同じ履帯の動き） |
| 右下 縦レバー（青緑） | 上 / 下 | 排土板を上げる / 下げる |
| 右上 のりかえボタン | タップ | ショベルカーに乗り換える |


- レバーは倒した量に比例して速さが変わり、離すと中央に戻る
- レバー両端の絵を押すと、その方向に最大で動く
- 別々の指で複数のレバーを同時に動かせる（例：ブーム上げ＋アーム引き＋バケット巻き込み）
- 指がレバーから外れても、画面から離すまで操作が続く
- 操作中の部位（ブーム・アーム・バケット・荷台・排土板）はレバーと同じ色でほんのり光る

**視点（カメラ）**

- 3D の画面（レバーやボタン以外の所）を指でなぞると視点が変わる。左右 = 車両のまわりを回り込む、上下 = 高さ（見下ろす角度）
- 2 回タップでいつもの斜め後ろに戻る。走り出すと少しずつ斜め後ろに戻る。乗り換え・はじめからでも戻る
- PC ではマウスのドラッグ・ダブルクリックで同じ操作
- ブルドーザーは、ゆっくり走るときは高い所から見下ろし（排土板の前の石が見やすい）、速く走ると目線が低くなって前の方まで見える

### ショベルカーの関節構造

```
Excavator (位置・向き)
├─ Crawler（左右の履帯。走行に合わせて履板が回る）
└─ UpperBody (rotation.y：上部旋回)
   └─ Boom (rotation.x)
      └─ Arm (rotation.x)
         └─ Bucket (rotation.x)
            └─ BucketTip（先端。地面判定用）
```

- 関節は可動範囲で止まり、油圧らしく加速・減速する
- 油圧シリンダーは取付点の間で毎フレーム伸縮する
- バケット先端は地面に深く入らない。アーム・バケットで地面に押し込むとブームが少し上がり、地面をなぞる

### ダンプカーの構造

```
DumpTruck (位置・向き)
├─ TruckBody（フレーム・キャブ）
├─ 前輪 ×2（ハンドルで向きが変わる）・後輪 2 軸（ダブルタイヤ）。走行に合わせて回る
└─ Bed (後端のヒンジで rotation.x：荷台の上げ下げ)
   └─ Tailgate（上端でぶら下がる後ろのあおり）
```

### ブルドーザーの構造

```
Bulldozer (位置・向き)
├─ 履帯 ×2（vehicles/shared/Tracks.tsx：ショベルと共通）・車体（BulldozerBody）
└─ Arm（根元で rotation.x：排土板の上げ下げ）
   └─ Blade（腕と逆に回して、いつも立った向きに保つ）
```

- 当たり判定は車体と排土板の kinematic ボディ。排土板の下の方は履帯の前まで厚くして、石が板と履帯の間に入り込まないようにしている
- `useBladePush.ts`：排土板の前 1.2m までの石の前向きの速さを「ブルドーザーの速さ〜+0.3m/s」におさえ、横すべりを弱める（押している手ごたえ）
- 土の山は足元の円（footprint。排土板の所にも円がある）で止まる。掘る処理はないので土ブロックは壊れない

### 岩をすくう・積む仕組み

岩は物理演算（Rapier）で転がり、ショベルカーの車体やバケットで押せる。
ただしバケットに載せたまま物理で運ぶと震えたりすり抜けたりしやすいので、補助ロジックを使っている：

- バケットの口が上〜横を向いているとき、岩の中心がバケットの中（口の少し外まで含む）に入ったら「すくえた」とし、物理を止めてバケットに追従させる
- バケットを開き始める（開き具合 30% 超で開く操作中）、開き具合 60% 超、または口が下を向くと、物理に戻して落とす。
  口が上を向いたままでも中に残らないよう、バケットから出るまで爪の方へ流し出す。出た瞬間、ダンプの荷台の近くなら落ちる先を荷台の中へ寄せる
- 荷台が下りているとき、荷台の中で落ち着いた岩は荷台に固定する（走っても落ちない）
- 荷台を上げると物理に戻し、あおりを開けて、荷台から出るまで後ろへ滑らせる

## 3D モデルについて

現在は Box / Cylinder などを組み合わせた仮モデル。GLB/GLTF に差し替えるときは
`vehicles/<車両>/parts/` の見た目の部品を置き換える（関節の Group とコントローラはそのまま使える）。
モデルを追加する場合は、商用利用の可否などライセンスを必ず確認すること。
